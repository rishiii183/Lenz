# ThreatLens — Project Documentation Pack

This folder contains the planning documents for the **Live DDoS Attack Map** project. Read these before implementation.

## Document order

1. `project-context.md` — project purpose, current decisions, terminology, constraints.
2. `PRD.md` — product requirements and MVP acceptance criteria.
3. `technical-architecture.md` — proposed system design and component boundaries.
4. `research.md` — source links, verified facts, research tasks, and open decisions.
5. `implementation-plan.md` — staged build plan and definition of done.
6. `AGENTS.md` — persistent instructions for Google Antigravity and other compatible coding agents.

## Current phase

**Phase 0: planning and verification. No implementation has been approved yet.**

The coding agent must inspect these documents, verify current APIs and library documentation, identify any contradictions or unknowns, and propose a plan. It must not start implementing the application until the user explicitly approves the plan.

## Core product truth

The product visualizes real, published DDoS statistics where available. It must not pretend that aggregated statistics are a second-by-second stream of individual attacks. Simulated animations are allowed only when clearly labelled as simulated and kept distinct from real observations.
